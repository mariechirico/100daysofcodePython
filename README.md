# 100 Days of Code: Python

## Running the files
- Mac OS = `python3 <filename>.py`
- Windows OS = `python <filename>.py`

### Files:
1. `Day4_task.py` - Rock, Paper, Scissors Game
2. `Day5_task.py` - Random Password Generator
3. `Day 7 - Hangman Game` - All the files needed to run the Hangman Game
  - Run the program from the `Day 7 - Hangman Game/main.py` file.
4. `Day8_task.py` - Caesar Cipher
5. `Day 9 - Silent Auction` - All the files needed to run the Silent Auction program
  - Run the program from the `Day 9 - Silent Auction/main.py` file. 
6. `Day 10 - Calculator Program` - All the files needed to run the Calculator program
  - Run the program from the `Day 10 - Calculator Program/main.py` file.
